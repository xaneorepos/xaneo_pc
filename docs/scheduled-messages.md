# Отложенные сообщения

На ПК нажмите правой кнопкой по кнопке отправки (или микрофону), чтобы открыть меню. Для сообщения с текстом или вложениями доступно «Отложить сообщение»; список отложенных доступен и при пустом поле. С клавиатуры меню открывается клавишей меню или Shift+F10 при фокусе в поле ввода.

На телефоне удерживайте кнопку отправки. Открыть список с пустым полем можно через меню прикрепления. На ПК дата выбирается в календарной сетке, время вводится с клавиатуры в 24-часовом формате. На телефоне используется купертиновский выбор даты и времени. Подтвердите сохранение. Обычное нажатие отправляет сообщение сразу; удержание микрофона сохраняет запись голоса/видео.

В списке можно изменить текст, добавить, заменить или удалить вложения, перенести время и отменить отправку. Изображения, видео и аудио отображаются соответствующими проигрывателями; остальные вложения — карточками файлов. Тексты интерфейса используют `messenger.scheduled.*` и поддерживают пользовательские языковые пакеты.

## Хранение и API

Оба клиента используют существующий серверный API `/api/v1/scheduled-messages/`. Задания хранятся в PostgreSQL, отправку выполняет серверный сервис `scheduled-messages`, поэтому клиент может быть закрыт. На сервере нужны API и worker из веб-реализации.

Создание использует постоянный `client_request_id`. После неоднозначного сетевого сбоя повтор сохраняет тот же шифротекст и время, чтобы не создавать дубликат. Черновик очищается только после подтверждения сервера. Редактирование передаёт исходные `expected_encrypted_text` и `expected_file_ids`, чтобы сервер обнаружил конфликт с другим устройством или отправкой.

Шифрование выполняется на клиенте. Для группы/канала ключ и фактический `epoch_id` берутся из одного свежего ответа сервера; при просмотре используются исторические ключи. Редактор отправляет только идентификаторы загруженных файлов. Оригинальные локальные файлы не удаляются. Медиа из списка загружаются только с endpoint скачивания на том же сервере.

## Модальные окна

Создание, список, редактор и перенос используют существующий `BaseCustomModal` клиента через `ScheduledModalShell`: на ПК — центральное окно с общей анимацией, на телефоне — мобильный нижний лист с учётом клавиатуры. Календарная сетка и ввод времени на ПК также открываются в кастомной оболочке. Во время сохранения закрытие формы заблокировано.

Оформление содержимого согласовано с формами создания группы/канала: заголовки и подписи над полями, заливка и тонкие рамки, общие радиусы, палитра и шрифты XNX. На ПК кнопки подтверждения расположены справа, на телефоне основная кнопка занимает всю ширину. Действия с вложениями и временем доступны под прокручиваемым содержимым редактора.
